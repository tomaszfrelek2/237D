Files for running radar (specifically DesignCore-RS-1843AOPU, though this code should be compatible with most TI mmwave radars).

`start` contains code for initializing and staring up the radar

`radar_driver` contains drivers and config files for the radar

`radar_visualizer` contains code for visualizing radar pointclouds

`radar_test` includes code for runnning the radar and collecting data, as well as misc. helper files
